## 🎯 前言

为什么要选择 Hugo + PaperMod？

### Hugo 的优势
1. **极速构建** - 上千页面秒级生成
2. **简单易用** - 单一二进制文件
3. **丰富主题** - 庞大的主题生态系统

### PaperMod 主题特色
- ✅ 响应式设计
- ✅ 深色/浅色模式
- ✅ 代码语法高亮
- ✅ 搜索功能

## 📦 安装与配置

### 1. 安装 Hugo 扩展版
\`\`\`bash
# Windows
# 下载 hugo_extended_*.zip
# 解压运行 hugo.exe version
\`\`\`

### 2. 创建新站点
\`\`\`bash
hugo new site myblog
cd myblog
git init
\`\`\`

### 3. 添加 PaperMod 主题
\`\`\`bash
git submodule add --depth=1 \\
  https://github.com/adityatelange/hugo-PaperMod.git \\
  themes/PaperMod
\`\`\`

## 🔧 核心配置

### config.yml 关键配置
\`\`\`yaml
baseURL: 'https://yourusername.github.io/'
title: '你的博客名称'
theme: 'PaperMod'

params:
  ShowReadingTime: true
  ShowCodeCopyButtons: true
  defaultTheme: auto
\`\`\`

## 💡 实用技巧

### 创建文章
\`\`\`bash
hugo new posts/文章标题.md
\`\`\`

### 本地预览
\`\`\`bash
hugo server -D
\`\`\`

## 📝 总结

Hugo + PaperMod 组合提供了：
- 🎨 美观现代的界面
- ⚡ 极致的性能体验
- 🔧 丰富的可配置性
